Design Principles

1. Clarity Over Decoration

Clean wireframe-style design prioritizes information hierarchy and readability. No unnecessary visual elements—every design choice serves purpose.

2. Respect Ghana's Heritage

The Ghana flag colors (red, gold, green) are integrated thoughtfully into the design, honoring national identity without overwhelming the experience.

3. Accessibility First

All components meet WCAG AA standards. Color is never the only differentiator. Text has sufficient contrast. Interactive elements are clearly defined.

4. Mobile-First Responsive

Design begins mobile, then scales up. Touch targets are always 44x44px minimum. Content reflows gracefully across all screen sizes.

5. Semantic & Meaningful

User interface patterns align with user mental models. Navigation is predictable. Content is organized logically. Actions are discoverable.

Button Best Practices

  • Minimum size: 44x44px (tap targets on mobile)
  • Label clarity: Action-oriented text ("Write Letter" not "Submit")
  • Hierarchy: One primary CTA per section/page
  • Spacing: Minimum 8px gap between adjacent buttons
  • Transitions: 0.2s smooth on all state changes

Forms & Inputs

Form design prioritizes clarity and accessibility. Each input has descriptive labeling, clear focus states, and helpful validation messaging.

Form Elements

Form Guidelines

  • Labels: Always visible, positioned above input (not placeholder)
  • Input height: Minimum 44px for mobile touch targets
  • Focus state: 3px red border with light red background
  • Placeholder: Optional, lighter color (#999), not replacement for label
  • Error messaging: Clear, specific, actionable
  • Spacing between fields: 1.5rem (lg)

Accessibility Guidelines

Color Contrast

AAA Compliant (Enhanced)
Contrast ratio: 7:1 — Excellent readability
AA Compliant (Standard)
Contrast ratio: 4.5:1 — Acceptable for body text

Touch Targets

  • Minimum size: 44×44px (buttons, links, interactive elements)
  • Spacing: Minimum 8px between adjacent touch targets
  • Focus indicators: Always visible, minimum 3px outline
  • Keyboard navigation: All interactive elements must be keyboard accessible

Text Readability

  • Line height: Minimum 1.5x font size (1.5–1.8 recommended)
  • Line length: 50–75 characters optimal for body text
  • Font size: Minimum 16px for body text on mobile
  • Color only: Never use color alone to convey information
  • All caps: Avoid extensive use; use lowercase with capitals for emphasis

Semantic HTML

<!-- Use semantic elements --> <nav>, <header>, <main>, <footer> <article>, <section>, <aside> <!-- Always pair buttons with proper types --> <button type="submit">Submit</button> <!-- Always use proper heading hierarchy --> <h1>Page Title</h1> <h2>Section Heading</h2> <h3>Subsection</h3> <!-- Always associate labels with inputs --> <label for="email">Email</label> <input id="email" type="email">

ARIA Attributes

  • aria-label="..." — For icon-only buttons or unlabeled elements
  • aria-describedby="..." — For extended descriptions of form errors
  • aria-live="polite" — For dynamic content updates (toast notifications)
  • aria-hidden="true" — For purely decorative elements
  • role="..." — Only when semantic HTML doesn't suffice
